# Art sources and replacement notes

The game ships with three locally bundled photographs. The copies were resized/compressed for web use. The title screen and courtroom backgrounds can be replaced by keeping these filenames, or by changing the corresponding CSS `background` URLs in `style.css`. GIFs can be used by changing a URL to a `.gif` file.

| Bundled file | Original work and source | License |
| --- | --- | --- |
| `assets/courthouse.jpg` | [US Courthouse El Paso exterior](https://commons.wikimedia.org/wiki/File:US_Courthouse_El_Paso_exterior.JPG), General Services Administration | U.S. federal government work; public domain in the United States |
| `assets/courtroom.jpg` | [Interior view of the court room at the Old Courthouse](https://commons.wikimedia.org/wiki/File:Interior_view_of_the_court_room_at_the_Old_Courthouse.jpg), Missouri History Museum; original photograph circa 1900–1920 | Public domain in the United States |
| `assets/police-car.jpg` | [Police-car.jpg](https://commons.wikimedia.org/wiki/File:Police-car.jpg), PublicDomainPictures.net | CC0 1.0 Universal Public Domain Dedication |

The three images are embedded locally; the game does not hotlink or download them at runtime. All photographs can be replaced with your own art. When replacing an image, check its license and update this file with the source and license. The rest of the graphics are page styling and typography created in the project.
